# Gaurav Patil: Portfolio

Next.js, TypeScript, Tailwind CSS v4 and Motion, exported as a static site.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # writes the static site to out/
```

- **Edit your content:** `src/content/site.ts` holds all text, links, projects and experience.
- **Deploy:** every push to `main` publishes the site to GitHub Pages through `.github/workflows/deploy.yml`.
